# Passive Workers — Glossary

- **Passive Workers** — the project: a network of contributed machines + non-transferable credit +
  open-source coordinator, producing varied intelligence.
- **The Council** — the first product: open-source mutual-aid collective intelligence. A task is run
  across diverse nodes and the answers are judged and merged into a better one.
- **Substrate** — the shared base (nodes + credit ledger + coordinator) that the Council and later
  markets are all built on.
- **Asker** — a participant who submits a task and spends credit.
- **Worker** — a contributor's machine running one model with a **lens** and a **country** tag; returns
  an **owned answer**.
- **Perspective** — one worker's answer; the council's diversity comes from many perspectives.
- **Lens** — an angle of attack given to a worker via its prompt (e.g. `opportunity`, `skeptic`,
  `first_principles`, `practical`) to pull different ideas from the same or different models.
- **Judge** — the component that **scores** candidate answers blind and **merges** them.
- **Merge** — the synthesized answer that keeps consensus, adds each perspective's unique points, and
  resolves disagreements — better than any single answer.
- **Coordinator** — the open-source, self-hostable hub holding the ledger, job queue, node registry,
  and telemetry. Routes tasks and settles credit.
- **Credit** — the non-transferable internal unit, denominated in normalized compute units. Earned by
  helping, spent by asking. Not a token; no secondary market.
- **Give/take rule** — you can't consume far beyond what you've contributed; a free-rider is blocked.
- **Owned deliverable** — a result a node's own agent produced and may share — as opposed to **proxied
  traffic** (tunneling someone else's packets), which is forbidden.
- **Model-downgrade** — the real cheat under a non-cash credit: a worker silently running a smaller or
  more-quantized model than claimed.
- **Cross-hardware verification** — confirming that honest answers from different hardware (e.g. Mac
  Metal vs VPS CPU) agree by *meaning* while a downgraded model is still caught.
- **Geo-diversity** — the moat: authentic in-country web/research presence that centralized APIs can't
  replicate.
- **TPSO** — Third-Party Settlement Organization (e.g. Stripe Connect) used for future cash payouts so
  KYC/AML sits with the processor.
